# Doa Web

O Doa Web é um projeto voltado à conexão entre pessoas interessadas em realizar doações e organizações não governamentais (ONGs), buscando facilitar o acesso a iniciativas sociais e incentivar a participação da comunidade em ações solidárias.

A proposta é utilizar a tecnologia como ferramenta de impacto social, oferecendo uma plataforma web na qual os usuários possam conhecer projetos, explorar iniciativas e encontrar oportunidades para contribuir com causas sociais.

O projeto representa a aplicação de conhecimentos de desenvolvimento web na construção de uma solução digital com propósito social, unindo tecnologia, acessibilidade e solidariedade.

## Objetivos

- Aproximar doadores de organizações e iniciativas sociais.
- Facilitar a divulgação de projetos que necessitam de apoio.
- Incentivar a participação em ações de impacto social.

## Tecnologias utilizadas:
- HTML5
- CSS3
- JavaScript
- Vercel (hospedagem e publicação)
